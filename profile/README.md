# Beeson Group

We are the research group of Prof. Ryne Beeson, in Mechanical and Aerospace Engineering at Princeton University. Our research is motivated by questions related to space flight, weather, and policy, and we develop theory and algorithms for data assimilation, optimal control, and dynamical systems. You can read more about the group on [our website](https://beeson.princeton.edu/).

Here we share the tools that we build for our own research and talks.

- [tycho](https://github.com/beeson-group/tycho) is a Python package for animated, interactive astrodynamics visualizations, each of which is a single HTML file that you open with a double click.
- [slides](https://github.com/beeson-group/slides) is our template for HTML slides, built on reveal.js, with an editor that runs in your browser.
- Each `talk-...` repository is one talk made from the slides template.

If you would like to contribute, please read our [contributing guide](https://github.com/beeson-group/.github/blob/main/CONTRIBUTING.md) first.
